## Problem Statement

Managing real-time urban rail transit systems (such as Cercanías Renfe) involves monitoring hundreds of active trains publishing updates every few seconds. Transport analysts and city authorities face a massive flow of raw streaming data, making it impossible to manually track delay hotspots, cancelled routes, or skipped stops as incidents unfold.

## The Solution: RailOps

**RailOps** is a dark-mode real-time observation dashboard running 100% on **IBM Z (LinuxONE)**. It ingests open GTFS-Realtime feeds from Renfe every 30 seconds, maps active train positions, aggregates route delay metrics, and leverages **IBM Granite 4.0** to automatically generate a validated, 3-sentence executive status report for any selected line or station zone.

---

## Key Features

* **Real-time Map Visualization:** Dark-themed interactive map built with Folium showing active train positions, route shapes, and color-coded delay status (Green <3 min, Orange 3-10 min, Red >10 min / Cancelled).
* **Automated Zone Analysis:** SQL-backed metric aggregation identifying lines and stations experiencing high delay percentages or service disruptions.
* **On-Premise Generative AI:** Uses **IBM Granite 4.0** running locally on LinuxONE to draft clear, 3-sentence executive summaries.
* **Zero-Hallucination Guardrail:** Integrated numeric validator (`validar_granite.py`) that cross-checks every single figure generated by Granite against the source JSON. Fallback template activation ensures 100% reliability.
* **Mainframe High-Throughput Metrics:** Built-in replay benchmark tool (`replay_carga.py`) to measure ingestion capacity and records processed per second on IBM Z hardware.

## Tech Stack & Architecture

* **Infrastructure:** IBM Z / LinuxONE Mainframe Community Cloud
* **Backend & Storage:** Python 3, SQLite (`mode=ro` read-only concurrent access)
* **AI & Validation:** IBM Granite 4.0 (`.gguf` via `llama-cpp-python`), Regex-based Fact Validator
* **Frontend:** Streamlit, Folium (`streamlit-folium`)
* **Data Sources:** Renfe Open Data (GTFS Static & GTFS-Realtime VehiclePositions, TripUpdates, Alerts)
